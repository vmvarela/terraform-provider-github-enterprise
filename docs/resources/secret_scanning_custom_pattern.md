# github_enterprise_secret_scanning_custom_pattern (Resource)

Manages a GitHub Enterprise Cloud secret scanning custom pattern. GitHub creates the pattern as `unpublished`; the API cannot publish it, so publish it from the enterprise secret scanning settings in the GitHub UI, where push protection for the pattern is also configured. Requires a token with `admin:enterprise`. Destroying the resource deletes the pattern and, by default, resolves its alerts; `post_delete_action = "delete_alerts"` deletes them irreversibly instead. Changing `name` replaces the resource, because GitHub does not allow renaming a pattern.

## Example

```hcl
# Defines an enterprise secret scanning custom pattern. GitHub creates it as
# unpublished; publish it from the enterprise secret scanning settings in the
# GitHub UI, where push protection for the pattern is also configured.
# Destroying this resource deletes the pattern and resolves its alerts.
resource "github_enterprise_secret_scanning_custom_pattern" "example" {
  provider = github-enterprise

  name    = "example-api-token"
  pattern = "(?i)example[a-z0-9_]{32}"

  must_match = ["^example"]
}
```

| `custom_pattern_version` | `String` | Read-only | Version of the pattern used for optimistic concurrency. GitHub requires it on every update and delete and rejects a stale value with HTTP 412. It changes on every write, so it stays unknown in an update plan. |
| `end_delimiter` | `String` | Optional | Delimiter GitHub must place after a match. GitHub applies a default when it is omitted, so the applied value is read back into state. Removing it from configuration does not clear a delimiter GitHub already applied. |
| `enterprise_slug` | `String` | Optional | Enterprise account slug. Defaults to the provider-level enterprise_slug. Changing it replaces the resource. |
| `id` | `String` | Read-only | Stable identity: enterprise_slug:pattern_id. |
| `must_match` | `List of String` | Optional | Regexes the secret must additionally match. The complete list is sent on every change, including when it is emptied. |
| `must_not_match` | `List of String` | Optional | Regexes the secret must not match. The complete list is sent on every change, including when it is emptied. |
| `name` | `String` | Required | Pattern name. Changing it replaces the resource: GitHub does not allow renaming a custom pattern. |
| `pattern` | `String` | Required | Regular expression that identifies the secret. GitHub evaluates it with Hyperscan (a subset of PCRE), so the provider only requires a non-empty value and leaves the syntax to GitHub. Changing it updates the pattern in place. |
| `pattern_id` | `Number` | Read-only | Numeric pattern ID assigned by GitHub. |
| `post_delete_action` | `String` | Optional | What GitHub does with the pattern's alerts when the resource is destroyed: `resolve_alerts` resolves them (the default), `delete_alerts` deletes them irreversibly. Changing it only updates what Terraform records; the value is sent to GitHub on destroy. |
| `push_protection_enabled` | `Bool` | Read-only | Whether push protection is enabled for this pattern. It is configured in the enterprise's secret scanning pattern configurations, not by this resource; GitHub only reports it here. |
| `slug` | `String` | Read-only | URL-friendly identifier GitHub derives from the pattern name. |
| `start_delimiter` | `String` | Optional | Delimiter GitHub must place before a match. GitHub applies a default when it is omitted, so the applied value is read back into state. Removing it from configuration does not clear a delimiter GitHub already applied. |
| `state` | `String` | Read-only | Publish state reported by GitHub. Created patterns arrive as `unpublished`, and the API has no operation to publish them; publish the pattern from the enterprise secret scanning settings in the GitHub UI. |
