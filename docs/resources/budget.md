# github_enterprise_budget (Resource)

Manages a GitHub Enterprise Cloud billing budget. A budget caps spending for one scope (enterprise, organization, repository, cost center, all users, all users of a cost center, or one user). GitHub enforces the cap server-side; this resource only declares it. **Destroying it removes the cap**; spending already incurred is unaffected. Amounts are whole dollars, or a number of licenses for license-based products. Requires an enterprise owner or billing manager token with `manage_billing:enterprise`; fine-grained tokens are not supported by these endpoints.

## Example

```hcl
# Caps what one organization can spend on Actions. GitHub enforces the limit;
# destroying this resource removes the cap.
resource "github_enterprise_budget" "actions" {
  provider = github-enterprise

  budget_scope          = "organization"
  budget_entity_name    = "my-org"
  budget_type           = "ProductPricing"
  budget_product_sku    = "actions"
  budget_amount         = 500
  prevent_further_usage = true

  alerts_enabled   = true
  alert_recipients = ["platform-owner"]
}

# AI credits are priced per bundle, so they use BundlePricing and a user scope
# requires the login and a blocking budget.
resource "github_enterprise_budget" "ai_credits" {
  provider = github-enterprise

  budget_scope          = "user"
  user                  = "octocat"
  budget_type           = "BundlePricing"
  budget_product_sku    = "ai_credits"
  budget_amount         = 30
  prevent_further_usage = true
  expires_at            = "2027-01-01"
}
```

## Schema

| Attribute | Type | Requirement | Description |
| --- | --- | --- | --- |
| `alert_recipients` | `List of String` | Optional | Logins that receive budget alerts. Rejected for `user` scope. |
| `alerts_enabled` | `Bool` | Optional | Whether GitHub sends budget alerts. Always disabled for `user` scope. |
| `budget_amount` | `Number` | Required | Budget amount in whole dollars, or a number of licenses for license-based products. Fractions are not accepted by the API. |
| `budget_entity_name` | `String` | Optional | Entity the budget applies to: organization login, `owner/repo`, or cost center UUID. Not used by `enterprise`, `multi_user_customer` and `user`. GitHub answers with the entity's display name, so a configured value is never overwritten and an imported budget records the display name until the next apply. Changing this value only updates what Terraform records; a budget cannot move between entities, so recreate it to target a different one. |
| `budget_id` | `String` | Read-only | Opaque budget ID assigned by GitHub. |
| `budget_product_sku` | `String` | Optional | Product or SKU covered by the budget, for example `actions`, `packages`, `codespaces`, `actions_linux` or `ai_credits`. Changing it replaces the budget. |
| `budget_scope` | `String` | Required | Scope the budget applies to: `enterprise`, `organization`, `repository`, `cost_center`, `multi_user_customer`, `multi_user_cost_center` or `user`. Changing it replaces the budget. |
| `budget_type` | `String` | Required | Pricing model: `ProductPricing` (all SKUs of a product), `SkuPricing` (one SKU) or `BundlePricing` (AI credits). Changing it replaces the budget. |
| `consumed_amount` | `Number` | Read-only | Amount consumed so far, in the budget's unit. Read-only; it changes without any configuration change. |
| `enterprise_slug` | `String` | Optional | Enterprise account slug. Defaults to the provider-level enterprise_slug. Changing it replaces the resource. |
| `expires_at` | `String` | Optional | Expiry date in YYYY-MM-DD format. Only supported for `user` scope. Changing it replaces the budget. |
| `id` | `String` | Read-only | Stable identity: enterprise_slug:budget_id. |
| `prevent_further_usage` | `Bool` | Required | Whether GitHub blocks additional spending once the budget is exceeded. Must be true for `user`, `multi_user_customer` and `multi_user_cost_center` scopes. |
| `user` | `String` | Optional | GitHub login the budget applies to. Required when `budget_scope` is `user`. Changing it replaces the budget. |
