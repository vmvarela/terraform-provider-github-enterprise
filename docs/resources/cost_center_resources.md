# github_enterprise_cost_center_resources (Resource)

Exclusively owns the **entire** assignment set of one cost center (users, organizations, repositories and enterprise teams). Anything not listed is removed, and **destroying this resource removes every assignment** of the cost center. Use one instance per cost center. Creation refuses a cost center that already has assignments: import it first (`terraform import ... enterprise_slug:cost_center_id`) so nothing is adopted implicitly. Before adding resources the provider lists all active cost centers and refuses any resource already held by another one instead of silently reassigning its billing; this check needs enterprise-wide visibility (an enterprise owner or billing manager token), because organization-owner tokens may see only part of the enterprise. Concurrent changes outside Terraform cannot be made atomic. Read maps GitHub types User, Org, Repo and Team to users, organizations, repositories and enterprise_teams; any other type or a blank name makes read fail without changing state.

## Example

```hcl
# Owns the ENTIRE assignment set of the cost center; destroying it removes all assignments.
resource "github_enterprise_cost_center_resources" "example" {
  provider = github-enterprise

  cost_center_id = github_enterprise_cost_center.example.cost_center_id

  # Placeholders: supply the exact names the GitHub API accepts. Formats are unverified here.
  users            = var.cost_center_users
  organizations    = var.cost_center_organizations
  repositories     = var.cost_center_repositories
  enterprise_teams = var.cost_center_enterprise_teams
}

```
